# Setup

Copy the contents of this folder into the `sharsud/sharsud` profile repository.

1. Keep `README.md` at the repository root.
2. Keep `.github/workflows/profile-visuals.yml` at the exact path shown.
3. Keep `assets/hero.svg` at the exact path shown.
4. Leave the `profile/` folder in place.
5. Commit and push.
6. Open GitHub → Actions → **Maintain profile visuals** → **Run workflow** once.
7. The workflow then refreshes the local SVG cards and contribution snake daily.

The README references only local `./profile/*.svg` assets for the statistics and snake.
